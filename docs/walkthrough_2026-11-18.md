## How this was measured

Each volunteer received the task text and the repository, nothing else. The observer started the session timer, recorded whether the volunteer reached a result that showed a source link and an as-of date, and whether anyone had to edit code, change configuration or install a dependency to get there. Editing code counts as a failure even if the result was eventually correct, because the acceptance criterion in the proposal is first use without editing.

The record contains no names: a random session id, a task letter, timings and two yes/no answers. Notes must not contain personal identifiers. Protocol: `docs/WALKTHROUGH_PROTOCOL.md`.

Known limitation: five volunteers who are computing students are not representative of the wider undergraduate population, and an observer in the room makes the task easier than using the tool alone. Both weaken the claim; neither is hidden here.
